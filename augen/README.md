# Augen

> **Note:** this workspace package is private since v2.219.1, so `@sjcrh/augen` is no longer published to the npm registry.
> Its latest published version there, 2.218.1-0, is frozen and outdated, and likely not what the latest container builds use:
> the release images install this workspace from a tarball that `container/pack.sh` packs from the source code.

Automatic generator of typescript-based server routes, unit tests, and API documentation.

## Install

```bash
npm install
```

## Develop

```bash
npm run dev
```

## Test

```bash
npm test
```
