Fixes:
- DMR scan: with the background correction on, the volcano is drawn on the excess over matched background rather than the raw delta-beta. The axis label, the |Δβ| cutoff, the hyper:hypo counts, the dot colours, both hover paths, the Manhattan plot's sides and the gene-body loss set now all read the same column as the corrected p-value. Previously the figure paired a corrected p with an uncorrected effect size, and the cutoff gated the two directions unequally on any cohort whose methylome has shifted.
- DMR scan: the background p is labelled "unadjusted p vs matched background" on the axis, the table, the hover and the exported provenance line, and the provenance no longer echoes the (inert, hidden) adjusted/original toggle. The number is unchanged: it was never multiplicity-adjusted, and a scan writes it to both p fields because the renderer picks one by pValueType.

Features:
- DMR scan blocks can be tested with covariates. utils/dnaMeth/build_block_matrix.py merges a scan export's adjacent same-direction DMRs into domain-scale blocks and builds an element matrix over the CpG shards, so the blocks go through diffMeth.R -- which fits ~ conditions + conf1 + conf2 -- instead of the scan's Rust fit, which has no design matrix and rejects confounders. A dnaMethylation elements[] entry can now set offerWithScanOnly to appear in the class picker on a scanOnly dataset. MMRF gains two such classes, dmr_block (whole span) and dmr_block_called (called intervals only).
- MMRF gains a "Proliferation score (8-gene cell cycle)" dictionary term, built offline from the bulk TPM matrix by ppmmrf/utils/scripts/build_proliferation_score.py and registered at init via termid2sample2value. The cohort ships no proliferation measure of its own, so this is what a differential-methylation or differential-expression contrast can be adjusted by. Covers 378 of the 415 methylation samples; a sample with no value is dropped from the contrast, not imputed.
- DMR scan: scan.permutation={seed} re-runs a scan with the group labels shuffled and group sizes preserved, for an empirical null. Debugmode only. utils/dnaMeth/permutationFdr.mjs drives B draws against a captured diffMeth payload and reports FDR = mean(null)/observed, purging each draw's cache entry. This is the only calibrated region-level FDR a scan can have: DMRcate's region FDR is not calibrated and the background correction's empirical p is floored at 1/(windows+1), so BH over a scan's tests is decided by how many regions were emitted rather than by the evidence.
