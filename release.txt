Features:
- Differential methylation runs on any regulatory element class, not just promoters. ds.queries.dnaMethylation gains an elements{} map keyed by what the client sends as element_type, and several classes may share one HDF5 by declaring element_class, so offering cCRE promoters and enhancer classes costs no extra files. The legacy .promoter key still works and stays the default when element_type is absent.
- Volcano run provenance in downloaded p-value tables now records the element class, alongside group sizes and every statistical setting. Hit counts are not comparable across classes -- the same contrast gives ~2,300 significant elements on ENCODE cCRE promoters and ~78,000 on TSS windows -- so a count without its class cannot be reproduced.
- dnaMethylation platform flag: platform:'wgbs' disables the group-mean imputation the array path relies on. WGBS missingness is a read-depth threshold rather than a probe-set mismatch, so imputing a group mean where the truth is "not sequenced deeply enough here" fabricates signal.
- dnaMethylation terms can be served from an element matrix when a dataset has no CpG-level .file. A promoter-only WGBS cohort could previously run differential methylation but had no way to read one element's value for one sample, so no violin by subgroup and no scatter against expression, even though the numbers were already in the element HDF5.
- Differential methylation plots per-element delta-beta by default, and the log2 fold-change controls are hidden for it. fold_change on M-values is a difference of logits: it ranks elements correctly but says nothing interpretable about how much methylation changed, so a log2 cutoff would set a limit in units the plot never shows. The effect-size cutoff applies to delta-beta instead (default 0.1, a 10-percentage-point change).
- Datasets choose which element class differential methylation opens on, via ds.queries.dnaMethylation.defaultElementType. Without it the volcano starts on the legacy promoter matrix regardless of what else the dataset offers.
- elementForTerms nominates which element matrix answers dnaMethylation term queries. A term carries coordinates but no element class, so a dataset serving several classes has to say which matrix a coordinate lookup should read.
- excludeSampleNamesMatching withholds non-comparable specimen types from differential methylation at the single eligibility gate every DM path already filters through, and is loud about a pattern that matches nothing.
- dnaMethylation is accepted as a correlationVolcano feature type.

Fixes:
- Region-based dnaMethylation terms take their unit from the matrix that serves them. An element matrix holding M-values was labelled "Average Beta Value", plotting values near -6 on an axis claiming a 0-1 scale.
- Differential analysis and scatter chart availability gate on the dnaMethylation getter rather than on a CpG-level .file, so a dataset offering only element matrices is no longer fully configured and unreachable.
