Features:
- DMR region analysis runs on datasets with no genome-wide CpG matrix, via per-chromosome CpG
  matrices (queries.dnaMethylation.cpgByChr), falling back per chromosome to the element matrix so a
  partial build degrades in resolution rather than erroring. MMRF also offers the CTCF-only and
  DNase-H3K4me3 cCRE classes.
- Volcano: "Center Δβ on median" (methylation, on the Δβ axis) moves the x origin to the median
  effect size. The significant-count line splits by direction ("15,707 hyper / 1,692 hypo"), counted
  server-side so the ratio is unaffected by the interactive-dot cap; the split also applies to gene
  expression and proteomics.
- DMR analysis can be launched from the group menu, not only by clicking a volcano hit. The picker's
  group colours carry into the region view, and hyper/hypo are one orange/blue pair everywhere. The
  region view shows a new ENCODE cCRE track beside the genes.
- dmrcate is 40% faster and uses 5x less memory on a genome-wide scan, with byte-identical output.

Fixes:
- dmrcate no longer emits thousands of false DMRs on a chromosome where NO probe passes per-CpG
  significance. When the per-CpG significant count was 0, the adaptive rule compared the smoothed
  FDR against the raw cutoff; smoothing pools ~25 probes, so that stays under 0.05 across a null
  chromosome. On MMRF male-vs-female, 12 of 22 autosomes reported 0 significant probes and
  963-4,570 DMRs each; the autosomal total goes from 20,963 to 5 over 15.9M probes, chrX unchanged.
- The element methylation getter returns values on the unit it advertises; a beta-unit entry was
  converted to an M-value and still labelled beta.
- The DMR region view's errors are visible. It wrote them into a div the rx update loop empties
  before every main(), so a failed region showed an empty sandbox.
- DMR analysis no longer reports "Group 1 needs at least 3 samples" on datasets whose sample groups
  carry ids without names (MMRF, GDC), and checks the sizes after id-to-name resolution, where a
  group actually shrinks.

General:
- MMRF requires files/hg38/mmrf/methylation/cpg/{chr}.h5 on the target host (~40GB), built by
  utils/dnaMeth/build_cpg_matrix.py. Without them the region view degrades to element resolution.
- The cCRE track needs anno/encodeCCREtrack.hg38.gz (+ .tbi), ~11MB, built by
  utils/dnaMeth/build_ccre_track.py from anno/encodeCCRE.hg38.gz. It is a reformat of a registry any
  host serving methylation elements already has; without it the locus view loses only that row.
